Welcome to MathArt

By UnrealCake8 · 11th June 2026 at 12:57am Gulf Standard Time (GMT+04:00)

Welcome to MathArt a website where you can make art using Desmos's Calculator Tool. Unlike Graphic Calculator Art, this time we’re stepping forward using pre-built APIs, confidence, and ideas shaped by the time we’ve already spent wanting to make art in a diverse way.

We’ve seen how others have made things, but this? This is by a student, for people by a single developer. This Website is a space, where you can create anything using Math. From Art to animations.

This website is proof that we’re contributors and creators with something to create. With this website, and fresh energy, we aim to make MathArt both enjoyable and easy to use.
